# 평생사주 웹툰 설계

작성일: 2026-09-23  
대상 저장소: `saju-webapp-main`  
상태: 구현 전 승인 설계

## 1. 목적

평생사주 상품을 설명하는 독립형 세로 스크롤 웹툰을 만든다. 독자는 30대 직장인 지호가 반복되는 선택의 이유를 궁금해하는 장면에서 시작해, 수달이 한 해의 운세가 아닌 인생 전체의 흐름을 펼쳐 보이는 과정을 읽는다. 마지막에는 기존 평생사주 입력·결제 페이지인 `/lifetime-report.html`로 이동한다.

성공 기준은 세 가지다.

1. 모바일에서 60~90초 안에 끝까지 읽을 수 있다.
2. 웹툰을 읽은 사람이 평생사주 100페이지 리포트가 무엇을 주는지 이해한다.
3. 기존 직접 구매 동선은 유지하면서, 이야기를 먼저 보고 싶은 사람에게 별도 진입점을 제공한다.

## 2. 범위

### 포함

- 16컷 평생사주 웹툰 스크립트와 이미지
- HTML 말풍선·나레이션을 사용하는 독립 페이지 `/webtoon/lifetime.html`
- 공통 웹툰 스타일과 에피소드 데이터
- 중간 CTA 1회와 최종 CTA 1회
- 홈의 대형 평생사주 홍보 카드에서 웹툰으로 들어가는 연결
- 모바일 접근성, 성능, 링크 및 카피 검증

### 제외

- 평생사주 리포트 생성 로직과 결제 흐름 변경
- 다른 상품의 웹툰 제작
- 운영자용 웹툰 편집기
- 사용자별로 대사가 달라지는 개인화 웹툰
- 구독, 포인트, 패키지, 990원 상품 추가

## 3. 사용자 흐름

```text
홈의 대형 평생사주 홍보 카드
  → /webtoon/lifetime.html
  → 16컷 웹툰
  → /lifetime-report.html
  → 기존 정보 입력·결제·PDF 생성
```

홈의 작은 평생사주 상품 타일은 계속 `/lifetime-report.html`로 직접 연결한다. 기존 구매 의도가 높은 사용자의 경로를 늘리지 않기 위해서다. 현재 홈 하단의 대형 평생사주 홍보 카드만 `/webtoon/lifetime.html`로 바꾸고 문구를 `웹툰으로 먼저 보기 →`로 조정한다.

웹툰 안에는 다음 링크만 둔다.

- 중간 CTA: `인생 전체의 흐름은 어떻게 이어질까` → 같은 페이지 다음 컷으로 스크롤
- 최종 주 CTA: `내 삶의 지도 펼쳐보기 · 14,900원` → `/lifetime-report.html`
- 최종 보조 링크: `무료 리딩 5종 먼저 보기` → `/services.html#free`

`services.html`의 무료 서비스 구간에는 현재 `id="free"`가 있으므로 별도 변경 없이 연결한다.

## 4. 이야기 설계

### 제목과 핵심 문장

- 제목: **한 번은, 내 삶의 지도를 펼쳐보고 싶었다**
- 주인공: 지호, 33세 직장인
- 핵심 전환 문장: **한 해씩 답을 찾는 대신, 내 삶 전체의 지도를 한 번 펴보는 편이 빠릅니다.**

수달은 미래를 단정하거나 답을 대신 정하지 않는다. 흩어진 경험을 한 흐름으로 연결해 주는 안내자다. 이야기는 불안에서 확신으로 가지 않고, 혼란에서 이해로 이동한다.

## 5. 시각 설계

### 기존 자산

- 캐릭터 기준: `public/illustrations/otter-field-guide.png`
- 배경·조명 기준: `public/hero/otter-hero-mobile.jpg`
- 상품 톤 기준: `public/tiles/lifetime.webp`

### 수달 고정 요소

- 갈색 수달, 사람 무릎 정도의 작은 체구
- 남색 두루마기, 금색 별자리 자수
- 크림색 속옷과 연보라 고름
- 금색 나침반
- 둥근 눈과 조용한 표정

### 지호 고정 요소

- 33세 한국인 남성 직장인
- 짧은 검은 머리, 검은 뿔테 안경
- 크림색 셔츠와 잿빛 남색 가디건
- 감정은 과장된 표정보다 어깨, 손, 시선으로 표현

### 화풍과 색

- 크림 종이 `#FFF9EF`
- 남색 잉크 `#17243D`
- 두루마기 청색 `#425B6B`
- 강조 금색 `#D5A542`
- 부드러운 수채 계조와 옅은 종이 질감
- 보라색 마녀, 고양이, 네온, 강한 검정 그림자를 사용하지 않는다

이미지는 글자, 말풍선, 가격, 버튼, 로고 없이 생성한다. 각 컷은 말풍선 위치에 따라 상단 또는 하단 25%를 단순한 배경으로 남긴다.

### 색온도 흐름

컷 01~06은 4500~6000K의 차가운 밤과 화면빛, 컷 07~12는 3600~4200K의 아침빛, 컷 13~16은 3000~3400K의 따뜻한 빛으로 이동한다. 빛의 변화가 주인공의 이해 변화를 대신 말한다.

### 에피소드 데이터

`episodes.js`는 제목, CTA, 이미지 경로, 대체 텍스트, 컷 간격, 말풍선을 데이터로 보관한다. `webtoon.js`는 이 데이터를 읽어 컷을 렌더링한다. 에피소드 키는 `lifetime`이다.

각 컷 데이터는 다음 필드를 갖는다.

```js
{
  src: '/webtoon/lifetime/cut-01.webp',
  width: 1080,
  height: 1350,
  alt: '이사 상자에서 오래된 수첩을 꺼내는 지호',
  gap: 'md',
  texts: [
    { type: 'narration', position: 'top-left', body: '이 수첩을 펼치면 늘 비슷한 문장이 나온다.' }
  ]
}
```

`lifetime.html`은 자바스크립트 실행 전에도 제목, 에피소드 설명, CTA가 보이게 한다. 컷은 데이터 렌더링을 쓰되, 실패하면 새로고침 안내와 `/lifetime-report.html` 직접 링크를 보여 준다.

### 이미지 규격과 성능

- 원본 작업 비율: 가로 1080px
- 일반 컷: 1080×1350, 클로즈업: 1080×900, 마무리: 1080×1600
- 최종 형식: WebP 품질 약 82
- 컷당 평균 목표: 230KB 이하
- 편 전체 목표: 4MB 이하
- 첫 두 컷만 즉시 로딩, 나머지는 지연 로딩
- 모든 `img`에 `width`와 `height` 지정

### 말풍선

말풍선과 나레이션은 HTML로 올린다. 이미지가 로드되지 않아도 대사는 읽혀야 한다. 말풍선 하나는 45자 이하, 한 컷 최대 3개다. `aria-describedby` 또는 `figcaption`으로 컷과 텍스트 관계를 제공한다.

## 7. 오류와 예외 처리

- 에피소드 데이터 로딩 실패: 오류 문장과 평생사주 직접 링크 표시
- 개별 이미지 로딩 실패: 대체 텍스트와 말풍선은 유지하고 깨진 이미지 아이콘은 숨김
- 자바스크립트 비활성화: `<noscript>`에서 상품 설명과 직접 링크 제공
- 모션 감소 설정: 스크롤 등장 애니메이션 제거
- 화면 폭 320px 이하: 말풍선은 컷 위 오버레이가 아니라 컷 아래 블록으로 전환

## 8. 측정

기존 분석 도구가 없다면 새 분석 SDK를 추가하지 않는다. 서버 로그로 구분할 수 있도록 홈에서 웹툰으로 가는 링크에 `?from=home-lifetime-story`, 웹툰에서 상품으로 가는 링크에 `?from=lifetime-webtoon`을 붙인다. 기존 페이지가 쿼리 문자열을 무시하므로 결제 흐름에는 영향을 주지 않는다.

추후 분석 도구가 연결되면 다음 이벤트만 추가한다.

- `lifetime_webtoon_open`
- `lifetime_webtoon_midpoint`
- `lifetime_webtoon_complete`
- `lifetime_webtoon_cta_click`

## 9. 검증

### 자동 검증

- 에피소드 데이터에 컷 16개가 있는지
- 모든 컷에 이미지 경로, 크기, 대체 텍스트, 간격 값이 있는지
- 말풍선 길이와 컷당 개수 제한
- 모든 내부 링크의 대상 파일 존재
- HTML에서 텍스트가 이미지에 의존하지 않는지

### 수동 검증

- 360px·430px 화면에서 처음부터 끝까지 스크롤
- 첫 화면에서 제목과 첫 컷이 자연스럽게 이어지는지
- 캐릭터 얼굴·의상·소품이 16컷에서 유지되는지
- 컷 12 전환 문장의 여백과 가독성
- 컷 16 이후 CTA가 `/lifetime-report.html?from=lifetime-webtoon`로 이동하는지
- 홈의 작은 상품 타일은 직접 결제 페이지로, 대형 홍보 카드는 웹툰으로 이동하는지
- 키보드 탐색, 포커스 표시, 모션 감소 설정 확인
- 편 전체 전송 용량 4MB 이하 확인

## 10. 완료 조건

- `/webtoon/lifetime.html`에서 16컷 전체가 끊김 없이 표시된다.
- 모든 대사와 가격은 HTML 텍스트이고 이미지 안에 포함되지 않는다.
- 최종 CTA의 상품명과 가격은 실제 평생사주 페이지와 일치한다.
- 기존 평생사주 정보 입력·결제·PDF 생성 테스트가 그대로 통과한다.
- 홈의 직접 구매 동선과 웹툰 진입 동선이 모두 작동한다.
- 모바일 검수와 자동 테스트가 통과하고, 생성 이미지의 인물 일관성을 사람이 확인한다.
