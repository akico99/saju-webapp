# 연애 구매 창: 받는 화면 예시 · 안심 문구 · 닫을 때 이유 묻기 (love-exit-v8)

2026-11-18

## 문제

무료 범위를 줄인 v7(11/17 11시 배포) 뒤로 무료 결과 112건에서 결제 버튼(UnlockClick, 브라우저 세션당 1회)이 30번 나왔지만 결제 시작(InitiateCheckout)은 0이다. 같은 날 운영 `/api/pay/start`와 결제 페이지가 정상 응답하는 것을 확인했으므로 고장이 아니라 구매 창 안에서 14,900원 결정을 못 하고 닫는 것이다. 구매 창은 이미 이메일이 채워져 있고 '모두 동의' 한 번이면 되므로 칸을 더 줄일 여지는 작다. 왜 닫는지는 측정하지 않고 있었다.

## 바꾼 것

- 구매 창에 결제하면 받는 화면 예시 3장(`/love-assets/preview/paid-1~3.webp`, 가상 인물 표기)을 넣었다.
- 결제 버튼 위에 '한 번만 결제 · 정기결제 없음 · 만들기에 실패하면 전액 자동 취소'를 굵게 올렸다(주문 동의 문구와 같은 사실).
- 처음 닫으려 할 때(×, 바깥 누르기, Esc) 한 번만 망설인 이유를 묻는다: 가격이 부담돼요 / 뭘 받는지 잘 모르겠어요 / 믿어도 될지 모르겠어요 / 지금은 아니에요. 고르면 짧은 사실 답과 '전체 풀이 다시 보기'를 보여 준다. '닫기'는 묻지 않고 닫는다. 결제 준비 중이거나 이미 물었으면 바로 닫는다.
- 이유는 `SoTrack.checkoutExit`가 이벤트 이름(ExitPrice·ExitUnclear·ExitTrust·ExitLater·ExitSkip)으로 세션당 한 번 보낸다. 픽셀 stats API가 맞춤 값을 나눠 보여 주지 않기 때문이다. GA에는 `checkout_exit`(reason).
- 화면 버전 love-exit-v8.

## 판단

배포 뒤 무료 결과 대비 결제 시작이 0에서 움직이는지, 닫는 이유 중 가격·내용·신뢰 중 무엇이 많은지 본다. 가격이 많으면 가격·작은 첫 상품은 사용자 결정으로 넘긴다.
