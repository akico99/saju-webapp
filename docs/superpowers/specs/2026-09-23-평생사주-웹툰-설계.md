# 평생사주 웹툰 설계 (방향 재설정판)

2026-09-23 방향 재설정. 16컷 서사형(주인공 지호, 날씨·지도 비유)은 폐기했다. 기준 레퍼런스는 [사주마녀 브랜드 페이지](https://witch.saju.com/brand)다.

## 레퍼런스에서 가져온 원칙

사주마녀 페이지는 폭 1125px짜리 긴 그림 4장을 이어 붙인 것이다. 그림은 6장 남짓이고 나머지는 글자가 끌고 간다. 우리가 따르는 원칙은 다음과 같다.

- 한 구간에는 한 메시지만 담는다. 컷을 늘려 설명하지 않는다.
- 제목은 굵은 디스플레이 글꼴로 쓰고, 강조어는 도장 박스로 찍는다.
- 말풍선과 자막은 반드시 디자인한다. 속마음은 손글씨 구름 말풍선, 자막은 테두리와 겹친 그림자가 있는 상자, 질문은 점선 타원으로 쓴다. 효과음과 이름표는 손글씨로 쓴다.
- 배경색은 장면마다 번지듯 넘어간다. 그림 가장자리 색을 섹션 배경색과 맞추고, 경계는 마스크로 흐린다.
- 캐릭터는 브랜드 마스코트(길잡이 여울)가 맡는다. 문제 장면에만 독자를 대신하는 인물이 나온다.

| 2. 전환 | 쉽게 풀어주는 사주 찾으시나요? → 사주보는 수달 | 크림 → 남색 #0F1B34 | 밤하늘에서 나침반을 내미는 여울 |
| 3. 서비스 | 어려운 용어를 매일 쓰는 말로 옮겨 드려요 → 평생사주 100쪽 | 남색 → 크림 #FDF6E8 | 책을 들고 설명하는 여울, 실제 리포트 첫 장 |

## 사실 확인 기준

웹툰에 적는 가격(14,900원), 사양(18장·약 100쪽·10분 안에 도착·3초 요약 카드), 무료 5종 이름은 `lifetime-report.html`과 `services.html`에 있는 내용과 같아야 한다. `test/webtoon.test.js`가 이를 검사한다.
