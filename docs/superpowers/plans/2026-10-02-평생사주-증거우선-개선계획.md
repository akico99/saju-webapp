# 평생사주 웹툰 증거 우선 개선 계획

> 작업자는 superpowers:executing-plans로 직접 구현하고, 마지막에 한 번 독립 검토한다.

목표: 사용자가 승인한 문제 → 쉬운 사주 제안 → 서비스 소개 흐름에서, 실제 3줄 요약과 생활 언어의 형광펜 결론을 먼저 보여준다.

구조: 기존 네 구간·캐릭터·상품 경로를 유지한다. 새 그림과 LLM 호출 없이 기존 공개 샘플을 발췌하고, 모바일 가독성을 HTML과 CSS로 개선한다.

기술: 정적 HTML/CSS, Node.js 계약 테스트, Puppeteer 모바일 검수, sharp의 공개 샘플 발췌.

설계 근거: ../사주-웹툰/분석/2026-10-02-사주-광고-벤치마킹과-웹툰-개선안.md (서비스 저장소의 상위 폴더 기준).

## 공통 제약

- 문서와 답변은 한국어. 기존 지침서의 골격과 사용자 확정 문장을 유지한다.
- 평생사주 14,900원, 18장·약 100쪽, 최대 10분. 무료 5종과 유료 PDF를 구분한다.
- 웹툰은 소개 형식이며 결과 리포트는 PDF/웹이다. 적중률·후기·광고 성과를 만들지 않는다.
- “한자는 빼고”와 3초 생성 보장 표현을 쓰지 않는다.
- 390×844 기준 실제 요약의 시작이 1,688px 이내여야 한다. 360·390·430px에서 잘림 없이 읽힌다.
- 공개 샘플 이미지의 내용은 바꾸지 않는다. 원본 링크와 발췌 출처를 기록한다.

## 검토 초점

1. 그림 높이를 줄일 때 얼굴·손·나침반과 말풍선이 서로 가리지 않는가.
2. 웹폰트 실패·모션 줄이기·자바스크립트 비활성에서도 증거와 버튼을 읽을 수 있는가.
3. 360px에서 긴 가격 버튼과 증거 문장이 잘리지 않는가.
4. 실물·HTML 발췌·제작 규칙을 구분하고 예시를 모든 구매자의 결과로 오해하게 하지 않는가.
5. 오래된 기획서·프롬프트에 “경쟁사에서 흔치 않음” 필수 조건이나 반복 승인 중단이 남지 않는가.
