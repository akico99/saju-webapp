# 용용사주 흐름 관찰과 연애 상품 반영

2026-10-28 사용자가 제공한 결과 화면·HTML 및 공개 상품 입력 화면 관찰. 제공 자료는 개인 입력 결과를 포함할 수 있으므로 이 문서에 개인 정보나 원문 전체를 복사하지 않는다.

## 직접 관찰한 입력
- 첫 화면은 상품의 핵심 약속과 CTA를 보여준다.
- 성별 → 생년월일·양/음력 → 시간 또는 모름 → 연애 상태 → 가장 궁금한 주제 → 직업 → 이름 → 자유 질문(선택) → 이메일 순으로 관찰했다.
- 앞선 관찰에서 생년월일을 건너뛴 것처럼 보인 것은 저장된 기존 값과 단계 전환을 제대로 구분하지 못한 오류였다. 값이 미리 채워질 수 있다.
- 이메일을 요구한 다음 무료 결과로 이동한다. 유료 결제 이후의 실제 결과는 확인하지 않았다.

## 무료 결과와 잠금
- 첫 화면에서 개인화 제목 및 명식을 보여주고, 사람 → 시기 → 위기 → 방법으로 이어진다.
- 장면마다 그림·짧은 말풍선·핵심 카드가 교대로 나타난다. 일부 날짜와 특성, 이미지, 행동 안내는 블러 또는 잠금 표시가 있다.
- 마지막에 유료 리포트 목차, 후기, CTA를 배치한다. HTML에 블러된 텍스트가 존재하는 경우가 관찰됐으나 우리 서비스에서는 유료 결과가 생성·구매되기 전 무료 DOM에 유료 답을 넣지 않는다. 잠금은 비개인화 자리표시자로 표현한다.
- 특정 날짜·상대 얼굴·상위 백분율·미래 보장 등은 용용의 주장일 뿐 계산 근거와 성과를 확인하지 못했다. 우리 상품에 근거 없는 수치를 만들거나 후기를 꾸며 넣지 않는다.

## 질문을 나눈 이유에 대한 가설
- 생년월일·시간·성별: 명리 계산의 입력 가능성. 실제 내부 처리 여부는 확인 불가.
- 관계 상태: 상황에 맞는 설명과 행동 안내를 분기할 가능성.
- 궁금한 주제: 결과에서 먼저 보여줄 내용 또는 유료 강조점을 조정할 가능성.
- 직업·자유 질문: 상황에 맞는 예시 작성 또는 고객 이해에 쓸 가능성. 계산값에 실제 반영되는지는 확인하지 못했다.
- 이름·이메일: 호칭과 결과 전달을 위한 입력으로 보이지만 운영 방식은 확인하지 못했다.

## 현재 적용
- 상황은 기존 서버 풀이에 반영한다.
- 가장 궁금한 주제는 선택 사항으로 추가하고, 무료 화면에서 유료 목차의 우선순위만 조정한다. LLM 해석이나 사주 계산에 반영한다고 주장하지 않는다.
- 직업과 자유 질문은 실제로 사용할 설계·개인정보 처리 근거가 준비되기 전에는 수집하지 않는다.
- 무료 결과에 숨겨진 답이 아닌 공통 자리표시자를 사용해 잠금 카드 두 개를 표시한다. 기존 가격·결제 로직은 유지한다.
