# 레퍼런스 기반 시각 재설계

사용자 요청: 청월당·타이트사주와 디자인 및 구성이 가까운 수준으로 비공개 구현. 앞선 전면 재작업 제안에 대한 실행 요청으로 진행한다.

## 설계
- 청월당 실제 홈에서 관찰: 약 448px 중앙 모바일 레이아웃, 카테고리 탭, 큰 캐릭터 배너, 가로 상품 카드, 고민별 컬렉션, 하단 메뉴.
- 타이트 실제 홈에서 관찰: 어두운 배경, 카테고리 탭, 캐릭터 배너, 하단 탐색 메뉴. 할인 팝업 이후 상세 동작은 확인하지 못했으므로 추정해서 보고하지 않는다.
- 선택: 청월당의 밝은 탐색 화면과 캐릭터 중심의 짙은 청록 상품 표지를 조합. 수달 브랜드/원화/문구를 사용한다. 고객 후기·판매량·할인은 지어내지 않는다.
- 기존 단일 상세 수정만으로는 사용자가 요구한 전체 구성이 되지 않으므로 별도 메인 미리보기를 추가. 운영 index.html은 건드리지 않는다.

## 구현
- [ ] /love-assets/home.html + showcase.css/js: 480px 중앙 레이아웃, 고민별 탐색, 대표 상품, 기존 상품 연결, 무료 체험, 하단 메뉴.
- [ ] /love.html: 새 원화 표지, 상황 공감, 캐릭터 소개, 결과 견본, 7장 구성, 가격/제공 범위, FAQ, 하단 시작 버튼.
- [ ] /love-assets/yeoul-cover.png: 내장 이미지 생성 도구로 제작한 독자 원화. 별도 세션의 원본 캐릭터와 동일한 이미지라고 주장하지 않는다. 프롬프트는 별도 파일로 기록.
- [ ] 기존 입력/무료 결과/로그인 이동 검증. 320/390/1280px 가로 넘침과 자산 로딩 확인.

## 경계
LOVE_TIMING_ENABLED=false이면 새 메인/자산도 기존 게이트에서 404. 결제/가격/해석 모델 변경 없음. 배포하지 않음. 유료 생성은 기존 크레딧 부족 상태로 별도 검수 필요.
