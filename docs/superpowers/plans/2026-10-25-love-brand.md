# 인연의 시기 브랜드 구현 계획

**Goal:** 사주보는 수달을 운영 브랜드로 유지하면서 독립 상품과 교체 가능한 해설 캐릭터를 가진 비공개 구매 경험을 만든다.
**Architecture:** 기존 love-funnel의 계산·주문·결제는 유지한다. 공용 상품 설정, 상품 소개, 입력, 미리보기, 결과를 같은 디자인으로 연결한다.
**Tech Stack:** Express, vanilla JS/CSS, node:test, Puppeteer.
**Spec:** 사용자가 2026-10-25 대화에서 승인한 8단계 구현안.

## 제약과 결정
- 기존 worktree codex/love-funnel에서 작업. 운영 배포·PG 문의 전송 없음.
- LOVE_TIMING_ENABLED 기본 꺼짐 유지, 새 자산도 게이트 적용.
- 인물 원본 미제공: 캐릭터 이미지 경로를 비워 두고 물결 장식으로 대체. 다른 인물을 임의로 확정하지 않음.
- 기존 19,900원 단건 가격 유지. 후보 가격 24,900원과 비회원 결제는 PG 확인 후 공개할 별도 변경으로 기록.
- 새 고객 약속은 현재 본문으로 제공 가능한 내용만 사용. 후기는 만들지 않음.

## 검토 초점
이미지 미제공/로드 실패, 모바일 가로 넘침, 무료 결과 재입력, 로그인 복원 및 주문 복귀, 새 정적 파일 게이트 우회.

## 캐릭터 이미지 교체
1. 승인한 원본을 public/love-assets/yeoul.webp 로 저장한다(세로형, 배경 없는 인물 권장, 가로 900px 안팎).
2. public/love-brand.js 의 character.portrait 를 '/love-assets/yeoul.webp' 로 바꾼다. 이름을 바꾸면 character.name·disclosure·love.html 의 '여울' 문구도 함께 바꾼다.
3. 이미지가 없거나 로드에 실패하면 물결 표지가 그대로 보인다. /love-assets 경로는 LOVE_TIMING_ENABLED 가 꺼져 있으면 404다.
