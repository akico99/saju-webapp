# 연애 상품 전체 경험 재구성

사용자 지시: 용용사주의 입력, 무료 결과, 결제 진입, 디자인 밀도를 실제 확인하여 구현한다. 기존 부분 수정 수준은 폐기한다. 기존 승인한 구현 범위 안에서 작업하며 운영 배포는 하지 않는다.

## 관찰한 근거
- 2026-10-28 IAB의 /bot/880058/form: 검붉은 배경, 한 질문씩 표시, 뒤로/다음, 작은 진행 점. 생일→시각→관계 상태→주제→직업을 직접 확인. 기존 관찰의 성별/이름/이메일도 기록에 있다.
- /result: 큰 원화, 중앙 카피, 그림 위 짧은 흰 타원 대사, 명식, 사람→시기→위기→공략, 문맥 안의 잠금, 상세 목차, 하단 고정 CTA.
- CTA 클릭: 하단 상품 선택창. 단품 35,900원, 2종 49,900원, 3종 62,900원. 쿠폰 및 약관 링크, 구매 버튼. 약관 동의/결제 실행 및 결제 후 화면은 관찰하지 않았다.

## 구현
- [x] 입력: 성별→날짜→시각→상황→상황별 관심 주제→호칭→확인. 기존 form/login 복원 계약 유지. 사용하지 않는 직업/이메일을 무의미하게 추가하지 않음.
- [x] 결과: 기존 명리 응답으로 개인별 제목/해설, 공통 원화와 짧은 편집 대사, 해설은 별도 읽기 지면. 긴 해설을 타원에 억지로 넣지 않음. 글자 손실 없음.
- [x] 같은 문맥에서 사람/시기/행동의 잠금 카드를 보여주고 구매창으로 연결. 무료 DOM에는 실제 유료 값 없음.
- [x] 실제 판매 7개 장을 네 개 시각적 파트로 소개. 제공하지 않는 얼굴/확정 날짜, 가짜 후기/할인/시간 제한은 만들지 않음.
- [x] 결제: 실제 단일 상품 가격 + 구매 내용 + 기존 PayFlow 진입을 접근 가능한 하단 dialog로 통합. 취소/키보드/로그인 복원 검증.
- [x] 원화: 동일 캐릭터의 공통 장면 제작. 유저별 이미지 생성 없음. CSS는 단일 스타일로 교체하여 누적 덮어쓰기 제거.
- [x] 검증: 모델 데이터 보존, 320/390/768/1280 오버플로, 이미지 실패, reduced motion, 입력 복원, 잠금 CTA, checkout focus/Escape. 실제 결제는 실행하지 않음.

## 소유권
Anthropic worker: love.html, love-app.js, love-redesign.css 및 입력/구매 테스트.
부모: love-reading-model.js, love-reading-view.js, reading.css, 삽화 및 읽기 테스트.
연결: opts.onUnlock 또는 bubbling love:unlock 이벤트. 테스트/로컬 DB만 사용.


## 구현·검증 기록
- 캐릭터 원화 4장 추가: cover-comic, thread-comic, timing-comic, door-comic. 기존 explain-comic 포함 총 5종으로 읽기 화면을 구성. 이미지 요청은 제작 때만 실행하며 사용자 입력/결과에서 이미지 API 호출 없음.
- 입력은 7단계, 관계 상황에 따라 관심 질문 문구가 바뀜. 관심 질문은 무료 결과 표시/목차 강조에만 사용하며 백엔드 명리값이나 생성 프롬프트를 바꾸지는 않음.
- 무료 흐름: 개인화 도입·명식 → 매력·사람 잠금 → 계절·시기 잠금 → 근거 → 균형·행동 잠금 → 4개 파트로 묶은 7개 장 소개.
- 짧은 편집 대사와 원래 개인별 해설을 분리. 유료 원문·월별 탭·읽기 위치·체크 항목 보존.
- 잠금/고정 CTA/본문 CTA가 같은 구매 dialog를 엶. 상품/가격/구성/판매처/약관 링크 확인 후 기존 PayFlow 진입. 실제 결제 없음.
- 무료/유료 320·390·768·1280 폭, 이미지 실패, 원문 보존, reduced motion, 입력 복원, 구매 확인 전 유료 API 미호출을 테스트. 실제 브라우저에서 가상 입력→무료 결과→구매창까지 직접 확인.
- 남은 외부 검증: 참고 서비스의 결제 후 유료 내부 화면은 미구매 상태로 미열람. 우리 서비스의 인증된 실카드 결제는 이번 작업에서 수행하지 않음. 운영 배포/병합하지 않음.

## 제작 방식과 프롬프트 세트
내장 image_gen 사용. 공통 참조: 기존 greeting-comic.webp의 성인 여울(갈색 긴 머리, 호박색 눈, 별 머리핀, 아이보리 자수 한복, 와인색 리본). 모든 생성에 2:3 세로, 한국 로맨스 웹툰풍 반실사, 검붉은 배경 #100607, 글자·로고·말풍선 제외, 하단 여백을 요구했다.
1. cover-comic: 독자를 바라보며 턱 가까이에 붉은 인연 실을 든 반신. 상단 15%, 하단 30% 어두운 여백. 붉은 림라이트, 꽃벽/궁전 장식 제거.
2. thread-comic: 낮은 탁자에 앉아 양손으로 붉은 실을 들고 바라보는 장면. 얼굴 상단 중앙, 하단 35% 여백.
3. timing-comic: 오른쪽에 앉아 붉게 빛나는 천구의에 손을 얹은 장면, 뒤쪽 붉은 달. 왼쪽 위와 하단 여백.
4. door-comic: 이전 반신과 다른 전신 롱샷. 붉은 커튼을 열고 문 안쪽으로 손을 내밀며 뒤돌아보는 장면. 왼쪽과 하단 여백.
원본 PNG는 .codex/generated_images에 보관. 배포용 WebP는 public/love-assets/reading에 저장. 900px 폭·quality 88 변환.
