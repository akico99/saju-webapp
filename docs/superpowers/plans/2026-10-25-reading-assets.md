# 연애 리포트 읽기 자산 계획

상태: 계획 문서. 이미지 생성, 코드 수정, 테스트 실행은 하지 않았다. 실제 원화와 폰트 파일은 아직 없다.

## 원칙
- 자산은 사전 제작된 정적 파일만 쓴다. 런타임에 이미지 생성 API를 호출하지 않는다.
- 고객마다 이미지를 새로 만들지 않는다. 같은 원화를 모든 고객이 공유한다.
- 그림은 분위기와 장면을 돕는 역할이다. 사주 결과를 그림으로 예언하거나 외모·사건을 묘사하지 않는다.
- 글은 그림 위가 아니라 그림 아래 또는 말풍선 영역에 둔다. 사용자별 문장은 그림 위에 올리지 않는다.
- 글꼴은 본문 가독성을 우선한다. 장식 서체는 제목에만 제한적으로 쓴다.

## 자산 목록

캐릭터 여울 포즈 6종 (/love-assets/reading/{scene}.webp):

| 파일 scene | 용도 | 표정·자세 방향 |
| --- | --- | --- |
| greeting | 표지, 첫 인사 | 가볍게 손을 드는 밝은 인사 |
| explain | 오행·계절 등 설명 장 | 작은 메모판을 들고 설명하는 자세 |
| empathy | 감정 공감 장 | 고개를 살짝 기울인 차분한 표정 |
| thinking | 근거·분석 장 | 턱에 손을 얹은 생각하는 자세 |
| caution | 조심할 신호 장 | 부드럽게 한 손을 든 경계 표정, 위협감 없음 |
| cheer | 실천·마무리 장 | 양손을 살짝 올린 응원 자세 |

장면 그림 4종 (/love-assets/reading/{scene}.webp):

| 파일 scene | 용도 | 장면 방향 |
| --- | --- | --- |
| meeting | 만남이 생기기 쉬운 자리 | 카페나 모임처럼 사람이 자연스럽게 모이는 배경 |
| distance | 거리감, 관계의 신호 | 두 사람 사이 간격이 보이는 넓은 배경 |
| conversation | 대화와 공감 | 마주 앉아 이야기하는 장면 |
| new-start | 새 출발, 앞으로 12개월 | 계절이 바뀌는 길이나 창가 배경 |

제작 기준: 모든 파일은 WebP, 장면 그림은 가로 세로 비율을 고정한다. 제안 크기는 포즈 720×900, 장면 960×600이며 파일당 150KB 이하를 목표로 한다. 수치는 제작 후 확인한다.

## 텍스트 안전 영역
- 그림에 글자를 넣지 않는다. 장면 자산에 말풍선, 제목, 이름이 포함되면 안 된다.
- 그림 위에 겹치는 텍스트는 고정된 짧은 장 이름(예: 매력의 근거)만 허용한다. 최대 12자, 한 줄.
- 사용자 이름, 본문, 생성 문장은 그림 아래 본문 영역에 둔다.
- 얼굴과 주요 몸짓이 있는 영역은 텍스트가 덮지 않는다. 포즈 파일 하단 25%를 말풍선 영역으로 비워 둔다.
- 모바일 320px 폭에서 그림은 최대 폭 100%, 본문은 그 아래 세로로 배치한다.

## 타이포그래피 계층
- 본문과 UI: Noto Sans KR. 본문 16~18px, 줄간격 1.75~1.9, word-break: keep-all, overflow-wrap: anywhere.
- 장 제목: Gowun Batang을 제목 1단계에만 사용. 22~26px.
- 보조 설명과 라벨: 13~14px, 대비 비율 4.5:1 이상.
- 긴 본문은 자르지 않고 문단 단위로 나눈다. 말풍선 한 개는 1~3문장을 목표로 한다.
- 폰트 파일은 라이선스를 확인한 뒤 정적 파일로 제공한다. 외부 폰트 CDN 호출은 필요할 때만 쓴다.

## 누락과 예외 처리
- 그림 로드 실패 시 그림 영역을 숨기고 본문은 그대로 읽는다.
- 생성 필드(장 제목, 말풍선, 월 문장)가 비면 해당 블록만 생략하고 원문 전체 보기 링크는 유지한다.
- 이름이 길면 말줄임 없이 줄바꿈하며 레이아웃이 깨지지 않게 한다.
- 한글 줄바꿈은 어절 단위를 우선하고, 긴 영문이나 숫자만 강제 줄바꿈한다.

## 테스트 매트릭스

| 항목 | 확인할 조건 |
| --- | --- |
| 화면 폭 | 320, 390, 768, 1280px에서 가로 넘침과 텍스트 잘림이 없는지 |
| 관계 상황 | 솔로, 썸, 연애, 이별 각각 표지와 장 이름이 맞는지 |
| 긴 이름 | 20자 이상 이름이 표지와 말풍선에서 깨지지 않는지 |
| 한글 줄바꿈 | 조사만 다음 줄에 남지 않고 어절이 유지되는지 |
| 누락 그림 | 포즈 6종, 장면 4종 중 하나가 없어도 본문이 보이는지 |
| 누락 생성 필드 | 장 제목·말풍선·월 문장이 비어도 빈 상자가 남지 않는지 |
| 긴 문단 | 긴 블록이 잘리지 않고 끝까지 읽히는지 |
| 모션 | 동작 감소 설정에서 애니메이션이 생략되고 내용이 바로 보이는지 |
| 키보드 | 장 이동과 월 선택을 키보드로 조작할 수 있는지 |

자동 검증 결과는 구현 계약 문서의 완료 기록에 남긴다. 한글 조사가 항상 같은 줄에 붙는 것은 보장하지 않으며, 어절 우선 줄바꿈과 긴 문자열 넘침 방지를 적용한다.

## 2026-10-25 제작 반영
- 포즈 6종과 장면 4종을 생성해 `public/love-assets/reading/*.webp`로 저장했다. 가로 800px, 파일당 약 135~338KB, 합계 약 2.4MB. 지연 로딩한다.
- 원화는 공통 자산이며 사용자별로 생성하지 않는다. 이름과 풀이 텍스트는 HTML로 별도 렌더한다.
- 포즈 원화는 배경이 있는 이미지이므로 투명 캐릭터로 취급하지 않는다. 3:2 프레임과 상단 중심 크롭을 사용한다.
- 본문 Noto Sans KR, 제목 Gowun Batang은 기존 showcase의 Google Fonts 로딩을 사용한다. 폰트 파일을 새로 배포하지 않았으며, 로딩 실패 시 시스템 글꼴로 대체한다.
- 가상 인물 한 건을 실제 Claude API로 생성해 `reading-example.json`에 저장했다. 예시 화면에 가상 인물임을 명시한다. 이전 생성 크레딧 문제는 이번 실행에서 재현되지 않았다.
- 이미지 생성 방향: 기존 여울 커버의 성인 여성 캐릭터와 녹색·금색 의상을 유지하고 인사/설명/공감/생각/주의/응원 포즈, 만남/거리감/대화/새 출발 배경을 제작했다. 이미지 내 문자는 사용하지 않는다.
