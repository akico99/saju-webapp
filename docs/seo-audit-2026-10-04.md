# 사주보는 수달 SEO 점검 (2026-10-04)

대상: https://sajuotter.com (최신 커밋 2026-10-02)
방법: 운영 사이트를 `curl`로 받아 본 크롤러 시점 확인 + `scripts/buildSeo.js` 코드 확인.

- 메타·sitemap·robots는 `scripts/buildSeo.js` 한 곳에서 생성 (직접 수정 금지, 스크립트 수정 후 재실행)

## 우선순위

1. **2027 신년운세 대비** — 무료 사주 도감은 실제 현재 연도와 다음 연도를 계산하므로 `FORTUNE_YEAR`를 2027로 미리 올리면 설명과 결과가 어긋난다. 현재 2026 표기를 유지하고, 별도 2027 유료 신년운세 상품은 공개 설정에 맞춰 메타·사이트맵을 관리한다. 연도 변경 시 실제 계산 결과와 본문을 함께 확인한다.
2. **미커밋 `public/new-year.html` 처리** — 2027년 유료 신년운세 상품이며 카드사 승인 전에는 `NEWYEAR_ENABLED=false`로 페이지·결제가 닫혀 있다. SEO 생성기에 등록하되, 비활성 상태는 `noindex, follow`와 사이트맵·상품 목록 제외를 유지한다. 승인 후 활성화하고 같은 환경에서 `node scripts/buildSeo.js`를 다시 실행한다.
3. **질문 랜딩 추가** — "사주 궁합 보는 법", "이직운 언제 오나", "택일 이사 날짜" 등 질문 1개 = 페이지 1개. 첫 문단 직답 + FAQPage JSON-LD. AI 개요·네이버 AI 브리핑 인용에 가장 효과적
4. **본문 보강** — `today-preview`는 h1이 sr-only(화면 비노출), `field-guide`는 h2 없고 본문 3.4KB로 짧음. 서버 HTML에 설명·근거 문단 보강
5. **웹툰 페이지 JSON-LD** — 제목·설명은 있음. `buildSeo.js`의 `manageHead` 설정 조정
6. **네이버 서치어드바이저 확인(사용자 작업)** — 사이트 등록, sitemap 제출 상태 확인
