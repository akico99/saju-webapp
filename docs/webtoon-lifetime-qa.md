# 평생사주 웹툰 증거 우선 개정 검수

검수일: 2026-10-02. 대상: public/webtoon/lifetime.html, webtoon.css.

| 폭 × 높이 | 첫 요약 본문 y좌표 | 전체 높이 | 가로 넘침 | 디자인 웹폰트 |

같은 검수 스크립트로 측정한 개정 전 390px 요약 본문 시작은 4,112.13px였다. 개정본은 1,688px 이내 목표를 통과했다. 앞선 분석의 3,896px는 제목 좌표이므로 본문 좌표와 직접 비교하지 않는다.

- 첫 화면의 제목·속마음·휴대폰 장면, 요약 화면의 세 문장을 직접 확인했다.
- 첫 속마음 풍선은 인물 그림 위에 놓지 않고 위쪽 별도 행으로 이동했다. 실제 브라우저에서 세 폭 모두 얼굴 겹침 검사가 통과했다.
- 증거 캡처는 첫 요약 카드가 아닌 형광펜 원문 위치를 기준으로 다시 프레이밍한다. 원문 하단 y좌표는 360:383px, 390:353px, 430:353px이고 CTA 시작은 각 화면 776px이라 가리지 않는다. 이전 요약 위치 기준 캡처는 형광펜 인용문을 CTA가 덮는 것을 재현했다.
- 원본 펼치기 이미지가 정상 로드됐다. 첫 문제 그림은 즉시, 아래 그림은 지연 로딩한다.
- 모션 줄이기·JS 비활성에서 형광펜은 처음부터 표시되고 요약을 읽을 수 있다.
- 대체 글꼴에서도 가로 넘침이 없다. 마지막 문장은 고정 버튼 위 여백을 확보했다.
- 검수는 native wheel로 중간 화면을 거친다. headless의 instant 점프만 반복하면 지연 로딩이 중간 그림을 관찰하지 못하는 현상을 재현했다.
- 접힌 details의 이미지에도 getClientRects가 남는 것을 확인해 닫힌 원본 이미지는 초기 로드 대기에서 제외했다. 펼치기 동작에서는 별도로 검사한다.

캡처: output/webtoon-render/의 full-{폭}.png, viewport-{폭}.png, proof-{폭}.png. 캡처 파일은 git 제외 경로이며 다시 생성할 수 있다.

## 내용·사실 대조

- 평생사주 14,900원·18장·약 100쪽·최대 10분, 구매 경로와 무료 5종은 기존 계약 테스트로 대조했다.
- 표지 3문장은 public/webtoon/lifetime/report-cover.webp의 공개 홍길동 샘플 원문이다. HTML 발췌·모바일 재배치라고 명시했다.
- 형광펜 문장은 public/samples/slides/chapter1.png 마지막 총평 결론이다. 원문과 “꾸준함과 원칙”의 강조 위치를 직접 대조하고 원본 링크를 붙였다.
- 표지·본문·카드 샘플은 홍길동 1990-05-15 14:30 남 기준. 예시의 점수·문장은 모든 구매자에게 같은 결과를 약속하지 않는다.
- 전문용어 즉시 풀이·2~5곳 강조는 systemPrompt.js 및 textMarkup.js, 장 끝 실천 포인트는 chapterOutlines.js에서 확인했다.
- “한자는 빼고” 대신 어려운 용어의 즉시 풀이를 약속한다. “3초”를 생성 시간으로 쓰지 않는다.
- 웹툰은 소개, 결과는 PDF이며 무료 5종은 별도 간단 리딩이라고 표시했다.

## 테스트

PowerShell:

~~~text
node --test (Get-ChildItem -Recurse -File -Path test -Filter *.test.js | ForEach-Object FullName)
$env:SHOT_WIDTH='390'; node test/manual-screenshot-webtoon.js
~~~

- 전체 테스트: 최종 작업 트리에서 133/133 통과. 최초 기준 실행에서는 consent.test.js의 6개 HTTP 검사가 임시 포트의 fetch “bad port”로 실패했다. 해당 파일 재실행 6/6, 이후 전체 실행은 129/129와 최종 133/133 통과. 결제·동의 코드는 작업 범위 밖이라 수정하지 않았다.
- 모바일 검수 명령: 최신 수정 후 360·390·430 모두 종료 코드 0. 증거 시작·말풍선 겹침·인용문/CTA 배치·가로 넘침·글꼴·원본 펼치기·모션·JS 비활성·대체 글꼴 검사 포함.
- RESEND_API_KEY가 없는 로컬의 이메일 발송 안내는 기존 테스트 환경 메시지이며 외부 이메일은 보내지 않았다.
