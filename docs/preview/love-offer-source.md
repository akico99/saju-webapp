# 2026-11-14 연애 전체 풀이 안내의 원문 근거

- 가격: public/love-brand.js의 14,900원. 변경 없음.
- 상품 범위: 같은 파일의 7개 chapters를 3개 묶음으로 설명. 월별 흐름/관계 패턴·자리·신호/상황별 행동. 새로운 상품 내용은 추가하지 않음.
- 실제 생성 예시: public/love-assets/reading-example.json의 paid, ‘인연 신호가 강한 세 달’ 첫째 달 문단. 파일 notice는 ‘가상 인물의 정보로 실제 생성한 화면 예시입니다. 고객님의 분석 결과가 아닙니다.’
- 가상 인물: 수달, 상황 some. 고객 주문·후기·적중 사례가 아니다.
- 공개하는 원문 조각(기존 11/12 사용 조각을 보존):
  1. 표현하고 드러내는 기운과 연인을 뜻하는 별이 동시에 들어오는데
  2. 이 달엔 두 가지를 해 보세요. 첫째, 마음을 돌려 말하지 말고 좋아하는 감정을 직접 표현해 보는 거예요.
  3. 요일과 시간을 정한 다음 만남을 제안해서, 관계에 규칙을 만들어 보세요.
- 원문에서 날짜·중간 문장·끝부분을 생략해 ‘…’를 표시. ‘흐름을 해석하고’, ‘해볼 일을 제안해요’는 편집상 구분 제목이며 원문 인용이 아니다.
- 과거 예시 JSON의 free.price는 현재 운영 가격과 다르므로 읽거나 복사하지 않는다. 가격은 현재 상품표에서만 표시한다.
- 기존 생년월일/이메일 등 고객 자료를 새로 공개하지 않는다. 샘플을 열어도 현재 이용자의 유료 날짜를 드러내지 않는다.

## 변경 목적과 한계

현재 무료 범위와 전체 풀이의 추가 내용을 같은 카드에서 확인하고, 고정·상단 CTA가 전체 리포트를 안내하도록 한다. 전환율이 개선됐다는 뜻이 아니다. 같은 소재/가격에서 다음 관측을 해야 한다.

추적은 creative_id와 page_version을 기존 GA/Meta 상품 행동에 추가한다. page_version은 같은 탭의 해당 상품에만 유지한다. Meta 이벤트 관리자 숫자를 고유 사용자로 해석하지 않는다. GA 맞춤 측정기준을 보고서에서 사용하려면 이벤트 범위 creative_id/page_version 등록과 수집 확인이 별도로 필요하며 과거 데이터는 복원되지 않는다.
